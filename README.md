# 外汇宏观利差与货币强弱监控看板

G10 主要货币（USD、EUR、GBP、JPY、AUD、CAD、CHF、NZD、SEK、NOK）的 2 年期国债收益率、近 N 日动量、配对推荐、利差走势和汇率强弱。

## 运行

```bash
pip install -r requirements.txt
streamlit run app.py
```

浏览器会自动打开 `http://localhost:8501`。

## 自动更新

- 页面默认每 15 分钟自动刷新一次，侧边栏可改成 5 / 30 / 60 分钟或关闭。
- 官方收益率每天只公布一次（通常在当地收盘后，部分机构有 1 个交易日延迟），程序每 30 分钟检查一次有没有新数据。
- 汇率来自 Yahoo 行情，每 5 分钟更新一次，报价可能有几分钟延迟。
- 页面顶部显示页面刷新时间和两类数据的抓取时间。“数据来源与更新状态”里列出每个经济体的数据源和最新数据日期；超过 3 个工作日没有新数据会标“可能过期”并自动展开。
- 侧边栏“立即刷新数据”会清空缓存，马上重新抓取。

## 部署成在线网页（可选）

本地运行时，电脑关掉看板就停了。想随时用手机或浏览器打开，可以免费部署到 Streamlit Community Cloud：

1. 在 GitHub 新建一个仓库，把本文件夹里的文件全部上传（`tests/` 可以不传）。
2. 打开 <https://share.streamlit.io>，用 GitHub 账号登录，点 “Create app”。
3. 选择这个仓库，Main file path 填 `app.py`，点 Deploy。
4. 几分钟后会得到一个 `https://<名字>.streamlit.app` 的网址。每次打开都会从各国官方接口取最新数据，页面开着时按设定间隔自动刷新。

## 数据是不是官方的

| 数据 | 性质 |
| --- | --- |
| 各国 2 年期收益率（每个国家的第一数据源） | 官方：各国央行、财政部发布的数据 |
| 欧洲央行 AAA 欧元区 2 年期（德国央行失败时的备用） | 官方，但口径是 AAA 级欧元区国债曲线，和德债 2 年期接近但不相同 |
| yfinance `2YY=F`（美国的最后一个备用） | 非官方：2 年期收益率期货，只是近似值 |
| 汇率 | 非官方：Yahoo Finance 行情 |
| `tests/` 里的数据 | 模拟数据，只用于离线测试，程序运行时不会用到 |

页面“数据来源与更新状态”会写明每个经济体实际用的是哪个源。

## 为什么收益率不用 yfinance

Yahoo Finance 上没有这些国家的 2 年期国债收益率。`US02Y`、`DE02Y`、`JP02Y` 是 TradingView 的代码，yfinance 查不到。Yahoo 上唯一接近的是美国 2 年期收益率期货 `2YY=F`，程序把它当作美国的最后一个备用源。

所以收益率改用各国官方的免费接口（都不需要 API key），yfinance 只用来取汇率。

## 数据源

每个国家按顺序尝试，前一个失败自动换下一个；全部失败只会让该国显示“获取失败”，不影响其他模块。侧边栏“数据源状态”会列出每个源的报错。

| 货币 | 数据源（按尝试顺序） | 序列 |
| --- | --- | --- |
| USD | 美联储 FRED → 美国财政部收益率曲线 → yfinance `2YY=F` | DGS2 / “2 Yr” / 期货近似 |
| EUR | 德国央行 → 欧洲央行 | 德债 2 年期 / AAA 欧元区即期利率 2 年期 |
| GBP | 英国央行收益率曲线 zip 包 | 名义即期曲线 2.0 年 |
| JPY | 日本财务省 JGB 利率 CSV（当月 + 历史） | 2Y |
| AUD | 澳洲联储 F2 表 | FCMYGBAG2 |
| CAD | 加拿大央行 Valet | BD.CDN.2YR.DQ.YLD |
| CHF | 瑞士央行数据门户 | rendoblid 中的 2 年期 |
| NZD | 新西兰联储 B2 日度收盘 | 政府债券 2 年期 |
| SEK | 瑞典央行 SWEA | SEGVB2YC |
| NOK | 挪威央行通用收益率 | 3 年期（挪威没有 2 年期基准） |

汇率（yfinance）：`EURUSD=X`、`GBPUSD=X`、`AUDUSD=X`、`NZDUSD=X`、`JPY=X`、`CAD=X`、`CHF=X`、`SEK=X`、`NOK=X`。

### 验证情况（2026-09-26 用真实接口核对）

- 已用真实数据核对格式和数值：
  - 美国财政部：日度收益率表的 “2 Yr” 列；Alpha Vantage 转发的美国 2 年期与财政部原始数值逐日一致（3 月 20 日至 7 月 7 日，75 天）。
  - 加拿大央行 Valet（JSON，字段 `d` / `v`）。
  - 瑞典央行 SWEA（JSON，字段 `date` / `value`）。
  - 德国央行：`sdmx_json` 格式，序列为“上市联邦证券收益率曲线（Svensson 法）2.0 年剩余期限，日度”。
  - 挪威央行：`sdmx-json` 格式，3 年期。
  - 日本财务省：CSV 表头 `Date,1Y,2Y,…`，日期格式 `YYYY/M/D`。
- 瑞士央行：`rendoblid` 带 `fromDate` 参数时返回的序列为空。代码遇到这种情况，会改为不带日期参数再取一次，然后在本地截取。第一次运行请确认它成功。
- 未能核对：FRED（开发环境的读取工具打不开它的 CSV，Python 直接请求没有这个问题）、英国央行 zip 包、澳洲联储 F2、新西兰联储 Excel、欧洲央行（备用源）。

第一次运行时请看一眼页面上的“数据来源与更新状态”。如果某个源报错，报错信息里会写明原因（例如找不到哪一列、现有代码有哪些），改 `data_sources.py` 里对应的函数即可。

| 文件 | 作用 |


## 指标说明

- **动量**：最新值减去 N 个自然日前（含当日之前最近一个交易日）的值，单位 bp。
- **鹰鸽标签**：按 2 年期收益率从高到低排，最高为“最鹰派（利差最高）”，最低为“最鸽派（利差最低）”。
- **配对推荐**：收益率最高的货币对最低的货币。挪威用 3 年期，不参与配对。另外给出一组“动量最分化”的配对（近 N 日收益率上行最多对上行最少）。
- **货币强弱**：每个货币对美元的 N 日涨跌，减去 G10 十个货币（美元计为 0）的平均值，正数代表强于一篮子。

数据仅供研究，不构成投资建议。
